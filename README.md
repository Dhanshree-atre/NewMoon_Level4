## What This Product Does

Companies and DAOs today face a fundamental dilemma: public blockchains make every transaction, payment amount, and recipient balance visible to everyone in the world. 
- For organizational payroll, transparent ledgers leak sensitive salary bands, individual contractor rates, cap-table-adjacent equity percentages, and competitive compensation packages.
- As a consequence, Web3 startups and DAOs are forced to use traditional fiat banking rails (e.g., Deel, Rippling, Wise), forfeiting trustless settlement, programmable rules, and global financial accessibility.

**MidnightPay solves this directly:**
1. **Committed Budget & Solvency Proof:** An employer deposits and commits to an aggregate payroll budget for a given pay cycle (e.g., 100,000 NIGHT). Zero-knowledge circuits prove that total disbursements never exceed the committed budget (`totalDisbursed <= totalCommittedBudget`).
2. **Confidential Payouts:** Individual salary amounts, employee addresses, and payment schedules are kept confidential off-chain. Only a cryptographic commitment root is published.
3. **Double-Spend & Diversion Prevention:** Each payout derives a unique, deterministic nullifier from the recipient's private key and blinding salt. The contract guarantees funds cannot be claimed twice or diverted to unauthorized parties.
4. **Selective Disclosure for Employees:** Workers receive a private, cryptographic payment receipt they can selectively disclose to landlords, banks (for mortgage/loan applications), or tax authorities without leaking peer salaries or employer financial secrets.
5. **Aggregate Regulatory & Tax Auditing:** Auditors and tax authorities can cryptographically verify aggregate tax withholding compliance without inspecting individual employee compensation.

## Privacy Model

MidnightPay leverages Midnight's dual-state execution model, explicitly partitioning the state boundary into public ledger data, private witness inputs, and zero-knowledge circuit assertions:

### 1. Public Ledger State (Visible On-Chain)
- `employer`: 32-byte commitment to the employer's public identity.
- `currentCycle`: The active sequential payroll epoch index.
- `totalCommittedBudget`: Publicly committed total budget allocated for the pay period.
- `totalDisbursed`: On-chain running sum of verified disbursements.
- `payrollCommitment`: Cryptographic schedule root of individual allocations.
- `claimedNullifiers`: Key-value mapping of spent nullifiers to prevent duplicate claims.
- `complianceHash`: Cryptographic commitment to aggregate tax and regulatory withholding.
- `isClosed`: Lifecycle flag indicating whether the cycle is actively accepting claims.

### 2. Private Witness Inputs (Never Broadcast to the Ledger)
- `local_secret_key()`: The transaction caller's private key, retained in client browser memory.
- `get_recipient_claim_witness()`: Private 4-tuple containing `[recipientAddress, salaryAmount, blindingSalt, cycleId]`.
- `get_compliance_witness()`: Raw itemized breakdown of corporate tax and statutory benefits.

### 3. Proved via Zero-Knowledge Circuits
- **Budget Solvency:** Proof that the disbursement satisfies `totalDisbursed <= totalCommittedBudget`.
- **Entitlement Inclusion:** Proof that the claimed salary matches an exact leaf in the employer's committed payroll schedule root.
- **Nullifier Verification:** Proof that the nullifier was generated by the rightful owner of the claimant secret key without revealing the secret key or the salt.
- **Anti-Double-Spend:** Proof that the nullifier does not already exist in `claimedNullifiers`.
- **Non-Repudiation:** Proof of income for third-party verification through selective disclosure.

## Tech Stack

- **Smart Contract Language:** [Compact](https://docs.midnight.network) (v0.26 language pragma)
- **Zero-Knowledge Runtime:** `@midnight-ntwrk/compact-runtime` (v0.19)
- **Contract Compilation Toolchain:** Midnight `compact` CLI compiler (v0.5.3)
- **Frontend Framework:** React 18 + TypeScript + Vite 6
- **Styling:** Tailwind CSS + Lucide Icons
- **WebAssembly Engine:** `vite-plugin-wasm` for cryptographic proof evaluation
- **Testing Framework:** Vitest (in-memory simulator & circuit logic suite)
- **Target Blockchain:** Midnight Preprod Network

## Prerequisites

Before setting up or deploying MidnightPay, ensure you have:
1. **Lace Wallet (Midnight Edition):** Install the [Midnight Lace Wallet](https://midnight.network) browser extension. Configure your network to **Midnight Preprod**.
2. **Node.js:** Version **v22+** (recommended: Node v22.x or v24.x) and npm v10+.
3. **Docker Desktop:** Required if running local Midnight proof server containers or local dev-net nodes.
4. **Preprod Testnet Funds:** Request testnet tNIGHT and tDUST from the official Midnight Preprod Faucet.

## Setup & Run Locally

Clone the repository and install all dependencies:

```bash
git clone https://github.com/Dhanshree-atre/NewMoon_Level4.git
cd NewMoon_Level4

# Install npm dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## Run Tests

MidnightPay includes an automated test suite verifying contract deployment, cycle initialization, confidential salary claims, double-spend nullifier rejections, budget overflow guards, and compliance audits:

```bash
# Run Vitest test suite
npm test
```

Expected output:
```text
 ✓ tests/midnightpay.test.ts (6 tests)
 Test Files  1 passed (1)
      Tests  6 passed (6)
```

To compile the Compact contract source:
```bash
# Compile Compact contract to managed TypeScript and ZKIR
npm run compile
```

To build the production application bundle:
```bash
npm run build
```

## CI/CD

Continuous Integration is configured via GitHub Actions in [.github/workflows/ci.yml](.github/workflows/ci.yml).

On every push to `main` and pull request:
1. Provisions an Ubuntu environment with Node.js v22.
2. Installs the official Midnight Compact compiler (`compact-installer.sh`).
3. Installs project dependencies (`npm ci`).
4. Compiles the Compact contract (`compact compile contracts/midnightpay.compact managed/midnightpay`).
5. Executes the automated Vitest test suite (`npm test`).
6. Verifies production bundle creation (`npm run build`).
